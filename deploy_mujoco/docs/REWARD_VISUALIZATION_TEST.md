## ✅ 已完成的修改

1. ✅ 导入 `RewardPlotter` 类

## 🎨 预期效果

运行程序后，你应该看到：

### 1. MuJoCo Viewer 窗口
- 左侧 2/3：机器人仿真场景
- 右侧 1/3：5个奖励曲线图表（垂直堆叠）

### 2. 奖励图表布局（从上到下）
```
┌─────────────────────┐
│  smoothness         │ ← 红色曲线
├─────────────────────┤
│  pos_tracking_global│ ← 绿色曲线
├─────────────────────┤
│  pos_tracking_local │ ← 蓝色曲线
├─────────────────────┤
│  quat_tracking_global│ ← 黄色曲线
├─────────────────────┤
│  quat_tracking_local│ ← 品红曲线
└─────────────────────┘
```

### 3. 曲线特征
- **X 轴**：时间步（-300 到 0，相对当前）
- **Y 轴**：奖励值（自动缩放）
- **实时更新**：每个控制步更新一次（50Hz）
- **历史长度**：显示最近300步（约6秒）
- **颜色编码**：不同奖励项用不同颜色

## 🔍 如何判断成功

### ✅ 完全成功的标志
1. 窗口右侧出现5个图表
2. 每个图表都有曲线在滚动
3. 曲线颜色正确（红、绿、蓝、黄、品红）
4. Y 轴范围自动调整（不是固定的）
5. 控制台每50步打印奖励值
6. 曲线数值与打印的数值一致

### ⚠️ 部分成功
**现象**：看不到图表，但控制台有奖励打印
**可能原因**：
- MuJoCo 3.3.7 的 viewer API 差异
- OpenGL 上下文问题

**解决方法**：
- 检查是否有错误信息：`[警告] 奖励图表渲染失败`
- 如果有错误，把完整错误信息发给我

### ❌ 失败情况
**现象**：程序崩溃或报错
**立即做的事**：
1. 复制完整的错误信息
2. 注意是在哪一步出错的
3. 发给我，我会立即修复

## 🎯 已知的潜在问题和解决方案

### 问题 1：viewer.ctx 不存在
**错误信息**：`AttributeError: 'PassiveViewer' object has no attribute 'ctx'`

**解决方法**：需要使用不同的渲染方式，我会提供备用方案

### 问题 2：图表不显示
**现象**：程序正常运行，但看不到图表

**调试步骤**：
1. 检查控制台是否有 `[警告] 奖励图表渲染失败` 的信息
2. 尝试调整窗口大小
3. 检查 `reward_plotter.get_figures_for_viewer()` 是否返回空列表

### 问题 3：图表显示但曲线不更新
**现象**：图表存在，但曲线是静态的

**原因**：`reward_plotter.update(rewards)` 可能没有被调用

**检查**：确认控制台有奖励打印

## 📊 性能考虑

### 渲染开销
- 每帧调用 `mjr_figure` 5次
- 每次处理 300 个数据点
- 对 50Hz 仿真影响应该很小（< 1ms）

### 如果性能下降
可以尝试：
1. 减少历史长度：`RewardPlotter(history_length=150)`
2. 降低更新频率：只在奇数帧更新图表
3. 减少显示的奖励项（注释掉不需要的）
